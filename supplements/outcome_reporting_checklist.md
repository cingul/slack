# Outcome Reporting Checklist for Orthostatic Hypotension and Orthostatic Intolerance Intervention Trials

Use this checklist when drafting protocols, statistical analysis plans, abstracts, manuscripts, or case series.

## 1. Phenotype and eligibility

- [ ] Define the enrolled phenotype: OH, delayed OH, neurogenic OH, non-neurogenic OH, POTS, reflex syncope, mixed OI, venous outflow obstruction, or other.
- [ ] State diagnostic criteria and measurement method.
- [ ] Describe key exclusions that could explain orthostatic symptoms, such as anemia, dehydration, arrhythmia, medication-induced hypotension, active infection, or severe deconditioning.
- [ ] Report baseline severity and duration of symptoms.

## 2. Orthostatic hemodynamics

- [ ] Report posture sequence: supine-to-standing, seated-to-standing, active stand, or tilt.
- [ ] Report rest period before baseline BP/HR.
- [ ] Report BP and HR at baseline, 1 minute, 3 minutes, and later time points if delayed OH/OI is relevant.
- [ ] Report standing duration and reason for early termination.
- [ ] Report medication timing, meal timing, hydration status, compression garment use, and time of day.
- [ ] Report supine hypertension.

## 3. Symptoms and patient-reported outcomes

- [ ] Identify whether the PRO is a primary or secondary outcome.
- [ ] Use validated instruments when possible, such as OHQ for OH and COMPASS-31 for autonomic symptom burden.
- [ ] State recall period and scoring direction.
- [ ] Prespecify responder thresholds when used.
- [ ] Report missing-data handling.
- [ ] Report item-level symptoms when clinically relevant.

## 4. Function and quality of life

- [ ] Report standing tolerance and/or walking tolerance.
- [ ] Report syncope, presyncope, falls, and injuries with exposure time.
- [ ] Report activity limitation or ADL impact.
- [ ] Include a quality-of-life measure when feasible.

## 5. Medication burden

- [ ] Record medication name, dose, frequency, route, and timing.
- [ ] Report baseline and follow-up regimens.
- [ ] Report whether medication changes were protocolized, clinician-directed, or patient-directed.
- [ ] Use MEQ for OH-directed vasoactive medication burden when appropriate.
- [ ] For broader OI medication regimens, report class-specific dose changes rather than forcing MEQ.
- [ ] Report rescue medication and failed taper attempts.

## 6. Safety and harms

- [ ] Define adverse-event collection window.
- [ ] Report all-cause and intervention-related adverse events.
- [ ] Report severity, seriousness, relatedness, action taken, and outcome.
- [ ] Report supine hypertension, syncope, falls, and medication-taper complications.
- [ ] For procedures/devices, report access-site events, bleeding, thrombosis, neurologic complications, device failure, migration, restenosis, and reintervention.

## 7. Durability

- [ ] State the primary endpoint time point.
- [ ] Report all follow-up windows.
- [ ] Report loss of response, rescue therapy, medication re-escalation, hospitalization, and repeat intervention.
- [ ] For device/procedural trials, report patency or imaging follow-up when relevant.

## 8. Mechanism-specific endpoints

- [ ] Prespecify the mechanistic endpoint and why it reflects target engagement.
- [ ] Report acquisition and analysis methods.
- [ ] Report whether mechanistic improvement correlates with symptoms, hemodynamics, medication burden, or safety.

## 9. Interpretation

- [ ] Interpret each outcome domain separately before presenting any composite endpoint.
- [ ] Identify discordant responses.
- [ ] Avoid calling medication reduction a success if symptoms, falls, syncope, or severe hypotension worsen.
- [ ] State limitations related to measurement variability, missing data, unblinded assessment, and confounding.
